Research · Machine Learning

SmartPark - Configurable Dynamic Parking Area

Designed and developed an end-to-end, software-driven smart parking platform created to eliminate the massive space wastage caused by traditional static parking layouts. Instead of using fixed, pre-marked individual slots, the system treats the parking lot as a fluid grid to dynamically position and park any vehicle based on its exact dimensions. Fine-tuned a YOLOv5 (PyTorch) object detection model on the PKLot dataset to track real-time grid availability via an overhead web camera feed. Developed a custom Python algorithm that dynamically resizes space configurations on the physical hardware grid layout to maximize space efficiency. Prototyped the entire UI/UX in Figma and engineered the mobile application using React Native (Expo Go), integrating RESTful APIs, a MySQL database, and internal path guidance to route drivers directly from the entrance to their dynamically generated grid position.

Space Optimization Algorithm RESTful APIs React Native (Expo Go) YOLOv5 (PyTorch) MySQL Database Path Guidance Figma Hardware Grid System Python Web Camera

Research · Data Analytics

Analyzing the Relationship Between CO₂ & Emissions and Climate Change Indicators (2000 - 2023)

Executed a quantitative longitudinal research study using SPSS to analyze 24 years of global environmental data (2000 - 2023) across five countries: the USA, China, Germany, India, and Indonesia. Built multiple linear regression and ANOVA models to evaluate how carbon emissions directly drive average temperature hikes and sea level rise, while measuring the protective, risk-reducing benefits of forest conservation and renewable energy adoption.
